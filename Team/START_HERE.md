# START HERE — Control-Room

> این راهنمای ۵ مرحله‌ای برای شروع به کار هر ایجنت، مدل یا توسعه‌دهنده‌ای است که این پروژه را باز می‌کند.

---

### ۱. قوانین را بخوانید
ابتدا [AGENTS.md](../AGENTS.md) را بخوانید. ۵ قانون بنیادین (برنچ `main`، تغییرناپذیری اسناد زنده، ثبت چنج‌لاگ، گیت‌های سبز پیش از توقف، و هیچ ادعایی بدون پروب) در آنجا ثبت شده است.

### ۲. همگام‌سازی و خواندن وضعیت زنده
```bash
git pull origin main
```
تنها دو فایل [Team/WHERE_WE_ARE.md](WHERE_WE_ARE.md) و [Team/MAP.md](MAP.md) را برای آگاهی از وضعیت زنده بخوانید. از خواندن کامل سایر فایل‌ها خودداری کنید.

### ۳. وظایف را با پیام ندهید
هیچ دستوری در پیام‌های گفتگو معتبر نیست. تمام تسک‌ها باید به صورت یک فایل با ساختار JSON در مسیر `Team/tasks/pending/` ثبت شوند و شامل شرط قطعی ابطال‌پذیری (`falsifiable_by`) باشند.

### ۴. اجرای گیت‌ها قبل از تحویل
پیش از ثبت نهایی کار، گیت‌ها باید ۱۰۰٪ سبز باشند:
```bash
python Tools/run_gates.py
```

### ۵. ثبت چنج‌لاگ و پوش
تغییرات را در [Team/CHANGELOG.md](CHANGELOG.md) ثبت کرده و تغییرات را به `origin main` پوش کنید.
